Packaging and building a wheel

The artifact Fabric consumes is a wheel. This page declares the project in pyproject.toml, shows the repository layout and the complete module, adds tests that run without Fabric, and builds and validates the wheel on your machine.

PEP 621 and pyproject.toml in practice

PEP 621 defines how a project declares its core metadata (name, version, dependencies, Python requirement, authors, license) in a [project] table of pyproject.toml. Every mainstream build backend reads the same table, so the metadata is portable and the backend is a swappable detail. The living specification is maintained by the Python Packaging Authority, and the Packaging User Guide is the place to check current field syntax.

A pyproject.toml has three tables that matter here:

[build-system]
Which backend builds the package and what must be installed to build it. Always present, whichever backend you pick.
[project]
The metadata. name must be static; version can be static or declared dynamic and computed by the backend (for example from a Git tag).
[tool.*]
Backend and tool configuration, for example where setuptools finds packages and how pytest discovers tests.

Choosing a build backend

For a pure-Python library of utilities, any of the standard backends produces an identical wheel. Pick the one your team already operates.

Backendbuild-backendChoose it when
setuptoolssetuptools.build_metaDefault choice. Familiar, reads [project], supports the src layout and optional dynamic versioning through setuptools-scm.
hatchlinghatchling.buildYou want sensible defaults with almost no configuration and built-in version-from-VCS plugins.
flit-coreflit_core.buildapiTiny, single-package libraries where you want the least machinery.
uv_build / pdm-backenduv_build, pdm.backendYour team already standardized on uv or PDM for environments and locking.

Corrections to older templates

Many templates still show requires = ["setuptools>=68", "wheel"] and license = { text = "MIT" }. The wheel package is no longer needed in requires because setuptools provides the wheel build itself, and the table form of license is deprecated in favor of an SPDX expression string (license = "MIT") plus license-files. Setuptools needs version 77.0.3 or later for that form, so the examples here pin setuptools>=77.0.3.

Do not commit build output

Folders such as dist/, build/ and *.egg-info/ belong in .gitignore. A committed dist/ goes stale the moment the code changes, and people will upload the stale wheel because it is sitting right there. The only wheel that should reach an Environment is one built by CI from a tagged commit.

Why src/? With a flat layout, pytest run from the repository root can import the package straight from the working directory even if packaging is broken (a missing module, a forgotten data file). With src/ the package is importable only after installation, so the tests exercise what the wheel actually ships. The cost is one line in pyproject.toml: tell setuptools where to look.

FieldDecisionWhy
namecontoso-fabric-utils (distribution) versus contoso_fabric_utils (import)Tools normalize hyphens, underscores and dots to the same project name, and wheel file names use underscores. Keep one canonical spelling in documentation and notebooks: import with underscores.
versionStatic, bumped in the release pull requestThe wheel file name carries the version, so Environments, logs and changelogs all agree. See the versioning options below.
requires-python>=3.11, no upper boundMatch the Python version of the Spark runtime your Environment selects. Upper bounds on Python cause avoidable resolution failures when the runtime moves.
dependenciesEmptyFewer dependencies mean fewer conflicts with the runtime's preinstalled packages. Anything you do list is resolved at publish time in Full mode, and cannot be downloaded at all from workspaces that block public repositories.
optional-dependencies.testPySpark and Delta pinned to the runtime's minor versionsUnit tests run against the same engine behavior as production. This extra is never installed in Fabric.
license and license-filesSPDX expression plus fileThe current form per PEP 639. Use your organization's internal license identifier if the code is not open source.

Verify against Microsoft Learn

The Python, Spark and Delta versions in a Fabric runtime change as new runtimes are released and older ones retire. Check Apache Spark runtime in Fabric for the runtime your Environment selects, then align requires-python and the test extra with it.

The module code

This is the library's public surface. It is the notebook function from the previous page with the changes explained there: injectable session, safer defaults and metrics returned instead of printed.

"""Reusable ETL utilities for Microsoft Fabric Spark notebooks."""
from importlib.metadata import PackageNotFoundError, version

from .loads import full_load_overwrite, max_value, merge_upsert

try:
    __version__ = version("contoso-fabric-utils")
except PackageNotFoundError:   # source checkout that has not been installed
    __version__ = "0+unknown"

__all__ = ["full_load_overwrite", "max_value", "merge_upsert", "__version__"]
"""Load helpers for Delta tables in Fabric lakehouses."""
from __future__ import annotations

import logging
from typing import Any, Callable, Dict, List, Optional, Union

from pyspark.sql import Column, DataFrame, SparkSession
from pyspark.sql import functions as F

log = logging.getLogger(__name__)

RowFilter = Union[str, Column, Callable[[DataFrame], Column]]


def _spark(spark: Optional[SparkSession]) -> SparkSession:
    """Injected session, else the active one, else the default session."""
    if spark is not None:
        return spark
    return SparkSession.getActiveSession() or SparkSession.builder.getOrCreate()


def _require(columns: List[str], required: List[str], where: str) -> None:
    missing = [c for c in required if c not in columns]
    if missing:
        raise ValueError(f"Missing required columns in {where}: {missing}")


def _apply_row_filter(df: DataFrame, row_filter: Optional[RowFilter]) -> DataFrame:
    if row_filter is None:
        return df
    if isinstance(row_filter, Column):
        return df.filter(row_filter)
    if isinstance(row_filter, str):
        return df.filter(F.expr(row_filter))
    if callable(row_filter):
        condition = row_filter(df)
        if not isinstance(condition, Column):
            raise ValueError("row_filter callable must return a pyspark Column.")
        return df.filter(condition)
    raise ValueError("row_filter must be a SQL string, a Column, or callable(df) -> Column.")


def full_load_overwrite(
    *,
    source_table: str,
    target_table: str,
    transform_fn: Callable[[DataFrame], DataFrame] = lambda df: df,
    select_cols: Optional[List[str]] = None,
    select_and_cast: Optional[Dict[str, str]] = None,
    add_missing_as_null: bool = False,
    row_filter: Optional[RowFilter] = None,
    validate_required_cols: Optional[List[str]] = None,
    partition_by: Optional[List[str]] = None,
    num_repartitions: Optional[int] = None,
    overwrite_schema: bool = False,
    count_rows: bool = True,
    spark: Optional[SparkSession] = None,
) -> Dict[str, int]:
    """Overwrite a Delta table from a source table.

    Order of operations: read, validate, filter, transform, project or cast,
    write. Returns {"rows_written": n}; n is -1 when count_rows is False.
    """
    session = _spark(spark)

    df = session.table(source_table)                                    # 1) read
    if validate_required_cols:                                          # 2) validate
        _require(df.columns, validate_required_cols, f"source '{source_table}'")
    df = _apply_row_filter(df, row_filter)                              # 3) filter early
    df = transform_fn(df)                                               # 4) transform

    if select_and_cast:                                                 # 5) project and cast
        cols = []
        for name, dtype in select_and_cast.items():
            if name in df.columns:
                cols.append(F.col(name).cast(dtype).alias(name))
            elif add_missing_as_null:
                cols.append(F.lit(None).cast(dtype).alias(name))
            else:
                raise ValueError(
                    f"Column '{name}' not found after transform of '{source_table}'. "
                    "Pass add_missing_as_null=True to create it as a typed null."
                )
        df = df.select(*cols)
    elif select_cols:
        _require(df.columns, select_cols, "the transformed DataFrame")
        df = df.select(*select_cols)

    if num_repartitions:                                                # 6) write
        df = df.repartition(num_repartitions)
    writer = (
        df.write.format("delta")
        .mode("overwrite")
        .option("overwriteSchema", "true" if overwrite_schema else "false")
    )
    if partition_by:
        writer = writer.partitionBy(*partition_by)
    writer.saveAsTable(target_table)

    rows = session.table(target_table).count() if count_rows else -1   # 7) metrics
    log.info("full load %s -> %s: %s rows written", source_table, target_table, rows)
    return {"rows_written": rows}


def max_value(
    table: str, column: str, *, spark: Optional[SparkSession] = None
) -> Optional[Any]:
    """Return max(column) from a table, or None if it does not exist or is empty."""
    session = _spark(spark)
    if not session.catalog.tableExists(table):
        return None
    return session.table(table).agg(F.max(column)).first()[0]


def _last_commit(delta_table) -> tuple:
    """(version, operation, operationMetrics) of the latest Delta commit."""
    row = delta_table.history(1).select("version", "operation", "operationMetrics").first()
    return row["version"], row["operation"], (row["operationMetrics"] or {})


def merge_upsert(
    *,
    source_df: DataFrame,
    target_table: str,
    key_cols: List[str],
    update_cols: Optional[List[str]] = None,
    delete_when: Optional[str] = None,
    ignore_cols: Optional[List[str]] = None,
    skip_unchanged: bool = True,
    check_duplicates: bool = True,
    spark: Optional[SparkSession] = None,
) -> Dict[str, int]:
    """Upsert source_df into a Delta table with MERGE.

    Inside delete_when, ``s`` is the source and ``t`` is the target.
    update_cols   columns updated on a match (default: every written non-key column).
    delete_when   SQL condition on ``s`` that marks a source row as deleted.
    ignore_cols   source columns used only in conditions; never written.
    Returns {"inserted", "updated", "deleted"} from the commit's metrics.
    """
    from delta.tables import DeltaTable   # provided by the Fabric Spark runtime

    if not key_cols:
        raise ValueError("key_cols must not be empty.")
    ignore = set(ignore_cols or [])
    _require(source_df.columns, key_cols, "source_df")
    write_cols = [c for c in source_df.columns if c not in ignore]
    _require(write_cols, key_cols, "the written columns")
    update_cols = update_cols or [c for c in write_cols if c not in key_cols]
    _require(write_cols, update_cols, "the written columns")

    session = _spark(spark)

    if check_duplicates:
        dupes = (
            source_df.groupBy(*key_cols)
            .agg(F.count(F.lit(1)).alias("_n"))
            .filter(F.col("_n") > 1)
            .limit(1)
            .count()
        )
        if dupes:
            raise ValueError(f"source_df has more than one row per key {key_cols}; deduplicate first.")

    if not session.catalog.tableExists(target_table):                   # first run: create
        first = source_df.alias("s")
        if delete_when:
            first = first.filter(f"NOT COALESCE({delete_when}, false)")
        first.select(*write_cols).write.format("delta").saveAsTable(target_table)
        rows = session.table(target_table).count()
        return {"inserted": rows, "updated": 0, "deleted": 0}

    def q(name: str) -> str:
        return f"`{name}`"

    on = " AND ".join(f"t.{q(k)} = s.{q(k)}" for k in key_cols)
    changed = " OR ".join(f"NOT (t.{q(c)} <=> s.{q(c)})" for c in update_cols)

    target = DeltaTable.forName(session, target_table)
    before = _last_commit(target)[0]

    builder = target.alias("t").merge(source_df.alias("s"), on)
    if delete_when:                                                     # clause order matters
        builder = builder.whenMatchedDelete(condition=delete_when)
    if update_cols:
        builder = builder.whenMatchedUpdate(
            condition=changed if skip_unchanged else None,
            set={c: f"s.{q(c)}" for c in update_cols},
        )
    builder = builder.whenNotMatchedInsert(
        condition=f"NOT COALESCE({delete_when}, false)" if delete_when else None,
        values={c: f"s.{q(c)}" for c in write_cols},
    )
    builder.execute()

    version_after, operation, metrics = _last_commit(target)
    if version_after == before or operation != "MERGE":
        metrics = {}                                                    # nothing was committed
    return {
        "inserted": int(metrics.get("numTargetRowsInserted", 0)),
        "updated": int(metrics.get("numTargetRowsUpdated", 0)),
        "deleted": int(metrics.get("numTargetRowsDeleted", 0)),
    }

How the metrics are read

The merge result is read back from the table's Delta history (the commit made by this call), not from a second scan. The helper compares the table version before and after so that a merge that commits nothing reports zeros rather than the previous commit's numbers. Operation metric names come from Delta Lake; confirm them against the Delta version of your runtime when you upgrade.

Tests that run without Fabric

The library imports pyspark and delta, both of which the test extra installs locally. A session-scoped local Spark session with the Delta extensions is enough to test real behavior on tiny DataFrames.

import pytest
from pyspark.sql import SparkSession


@pytest.fixture(scope="session")
def spark(tmp_path_factory):
    from delta import configure_spark_with_delta_pip

    warehouse = tmp_path_factory.mktemp("warehouse")
    builder = (
        SparkSession.builder.master("local[2]")
        .appName("unit-tests")
        .config("spark.sql.extensions", "io.delta.sql.DeltaSparkSessionExtension")
        .config("spark.sql.catalog.spark_catalog", "org.apache.spark.sql.delta.catalog.DeltaCatalog")
        .config("spark.sql.warehouse.dir", str(warehouse))
        .config("spark.ui.enabled", "false")
        .config("spark.sql.shuffle.partitions", "2")
    )
    session = configure_spark_with_delta_pip(builder).getOrCreate()
    yield session
    session.stop()

import pytest

from contoso_fabric_utils import full_load_overwrite, max_value, merge_upsert


def _save(spark, rows, schema, name):
    spark.createDataFrame(rows, schema).write.format("delta").mode("overwrite").saveAsTable(name)


def test_full_load_filters_and_counts(spark):
    _save(spark, [(1, False), (2, True)], "order_id int, is_deleted boolean", "src_orders_a")

    result = full_load_overwrite(
        source_table="src_orders_a",
        target_table="tgt_orders_a",
        row_filter="coalesce(is_deleted, false) = false",
        spark=spark,
    )

    assert result == {"rows_written": 1}
    assert [r.order_id for r in spark.table("tgt_orders_a").collect()] == [1]


def test_full_load_names_the_missing_column(spark):
    _save(spark, [(1,)], "order_id int", "src_orders_b")

    with pytest.raises(ValueError, match="Missing required columns"):
        full_load_overwrite(
            source_table="src_orders_b",
            target_table="tgt_orders_b",
            validate_required_cols=["order_id", "quantity"],
            spark=spark,
        )


def test_max_value_is_none_for_a_missing_table(spark):
    assert max_value("table_that_does_not_exist", "id", spark=spark) is None


def test_merge_upsert_inserts_updates_and_deletes(spark):
    _save(spark, [(1, "open"), (2, "open"), (3, "open")], "order_id int, status string", "silver_orders_c")
    changes = spark.createDataFrame(
        [(1, "closed", False),    # matched, changed      -> update
         (2, "open", True),       # matched, flagged      -> delete
         (3, "open", False),      # matched, unchanged    -> untouched
         (4, "open", False),      # new key               -> insert
         (5, "open", True)],      # new key, flagged      -> skipped
        "order_id int, status string, is_deleted boolean",
    )

    result = merge_upsert(
        source_df=changes,
        target_table="silver_orders_c",
        key_cols=["order_id"],
        delete_when="s.is_deleted = true",
        ignore_cols=["is_deleted"],
        spark=spark,
    )

    assert result == {"inserted": 1, "updated": 1, "deleted": 1}
    rows = {r.order_id: r.status for r in spark.table("silver_orders_c").collect()}
    assert rows == {1: "closed", 3: "open", 4: "open"}


def test_merge_upsert_rejects_duplicate_keys(spark):
    _save(spark, [(1, "open")], "order_id int, status string", "silver_orders_d")
    dupes = spark.createDataFrame([(1, "a"), (1, "b")], "order_id int, status string")

    with pytest.raises(ValueError, match="more than one row per key"):
        merge_upsert(source_df=dupes, target_table="silver_orders_d", key_cols=["order_id"], spark=spark)

The tests run on a laptop or a GitHub runner in a minute or two once Spark's Delta jars are cached. Add a test for every transformation you share, using three-row DataFrames that include a null, a duplicate and a boundary value.

The .whl in dist/ is the distributable package. Upload only that file to Fabric. The .tar.gz source distribution is useful for a package feed but is not what an Environment installs for a Python library.

Key takeaways

  • Declare everything in pyproject.toml: setuptools 77.0.3 or later, an SPDX license string, requires-python matching the runtime, and the src layout.
  • Keep runtime dependencies empty; PySpark and Delta come from the Fabric runtime and belong only in the test extra.
  • Test the installed package against a local Spark session so packaging mistakes fail on your machine.
  • Never commit dist/; the only wheel that reaches an Environment is the one CI built from a tag.
  • Verify the built wheel in a clean virtual environment before you upload it.
