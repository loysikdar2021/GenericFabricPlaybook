Incremental loads and MERGE

An incremental load applies only what changed since the last run. It is cheaper than a full reload and much easier to get subtly wrong. This page explains the two mechanisms that find the changes, gives a reusable Delta MERGE utility for Silver, shows how deletes reach Silver and lists the failure modes to design for.

  • Focus watermarks, MERGE, deletes

The watermark column

A watermark column, or high-water mark, is a column in the source that records when a row was created or last changed, typically a last_modified_utc timestamp the source application sets on every insert and update. By remembering the highest value already loaded, a load can ask the source for only the rows above it.

Monotonic
Values only increase as rows change. A column that can be set backwards, or that a bulk fix rewrites with old values, cannot serve.
Maintained by the source
The source sets it on every change, including changes made by batch jobs and manual fixes, not only by the main application.
Precise enough
A date without time, or a timestamp rounded to the minute, puts many changes on the same value; the load must then re-read the boundary value.
Indexed or partition-aligned
Where the source is a database, a filter on the column should be cheap. In Bronze Delta tables the column should support file skipping.
  1. Initial load

    The first run has no mark, so it loads everything. On success it records the maximum watermark it loaded.

  2. Store the mark

    Keep it in a control table (source, column, last value, run id) or derive it from the target table itself. The utility below supports both.

  3. Read the mark

    Each later run starts by reading the stored value.

  4. Extract the slice

    Select source rows whose watermark is greater than the mark, minus an optional lookback.

  5. Load

    Deduplicate to one row per key and MERGE into the target.

  6. Advance the mark

    Only after the MERGE has committed, store the slice's maximum watermark. Advancing first and failing later loses rows silently.

The primary key approach

Where there is no reliable modified timestamp but the table has a sequential, ever-increasing key such as an identity column, the key itself can act as the mark. Each run loads rows whose key is above the highest key already loaded.

Example: the Contoso customers source has an auto-incrementing customer_id. The initial load takes every row; the highest id is 5000, so 5000 is stored. The next run asks for customer_id > 5000 and receives the 150 customers created since, the highest being 5150, which becomes the new mark.

This finds new rows only. An update to customer 4200 does not change its key, so the key approach never sees it. Use it for append-only or insert-heavy tables (events, log-like order lines that are never edited), or combine it with a periodic full comparison for the few updates that do happen.

Choose per table, and combine where needed: a watermark for inserts and updates plus one of the delete strategies below is the most common production answer. Between Fabric layers you can also read the Delta change data feed of the upstream table, if it is enabled there, instead of filtering on a watermark.

The utility derives the mark from the target by default and accepts an explicit watermark_value from a control table. It returns new_watermark, which the caller writes to the control table only after the call returns without an exception. The Control-Table Pipelines playbook covers the control table itself.

The reusable incremental MERGE utility

The utility performs an SCD type 1 upsert: the target keeps one current row per key and changes overwrite it. It is table-agnostic; everything table-specific is a parameter. Put the helpers and the function in one module, ideally a library attached through the Environment (see Shared Python Libraries), or in the first code cell of the notebook while you develop.

Helper functions

from datetime import datetime, timedelta
from functools import reduce
from typing import Any, Callable, Dict, List, Optional, Sequence, Tuple, Union

from delta.tables import DeltaTable
from pyspark.sql import Column, DataFrame, SparkSession, Window
from pyspark.sql import functions as F
from pyspark.sql.types import StringType

RowFilter = Union[str, Column, Callable[[DataFrame], Column]]


def table_exists(spark: SparkSession, name: str) -> bool:
    """True if the (optionally schema-qualified) table is registered in the catalog."""
    return spark.catalog.tableExists(name)


def resolve_columns(df: DataFrame, wanted: Sequence[str]) -> List[str]:
    """Actual (case-correct) names of the wanted columns that exist in df."""
    by_lower = {c.lower(): c for c in df.columns}
    return [by_lower[w.lower()] for w in wanted if w.lower() in by_lower]


def choose_key(df: DataFrame, candidates: Sequence[Sequence[str]]) -> List[str]:
    """First candidate key whose columns all exist in df (case-insensitive)."""
    for group in candidates:
        found = resolve_columns(df, group)
        if len(found) == len(group):
            return found
    raise ValueError(f"No candidate key found. Tried {list(candidates)}; columns: {df.columns}")


def watermark_column(df: DataFrame, wm_cols: Sequence[str]) -> Column:
    """coalesce() of the watermark columns that exist in df, cast to timestamp."""
    present = resolve_columns(df, wm_cols)
    if not present:
        raise ValueError(f"None of the watermark columns {list(wm_cols)} exist in {df.columns}")
    return F.coalesce(*[F.col(c).cast("timestamp") for c in present])


def last_watermark(spark: SparkSession, target_table: str, wm_cols: Sequence[str]) -> Optional[datetime]:
    """Highest watermark already present in the target; None if the target has no watermark column."""
    tgt = spark.table(target_table)
    present = resolve_columns(tgt, wm_cols)
    if not present:
        return None
    expr = F.coalesce(*[F.col(c).cast("timestamp") for c in present])
    return tgt.agg(F.max(expr)).first()[0]


def latest_per_key(df: DataFrame, key_cols: Sequence[str], order_col: str = "_wm",
                   tiebreak_cols: Sequence[str] = ()) -> DataFrame:
    """Keep one row per key: the newest by order_col, then by tiebreak_cols (deterministic)."""
    order = [F.col(order_col).desc_nulls_last()] + [F.col(c).desc_nulls_last() for c in tiebreak_cols]
    w = Window.partitionBy(*key_cols).orderBy(*order)
    return df.withColumn("_rn", F.row_number().over(w)).where(F.col("_rn") == 1).drop("_rn")


def apply_row_filter(df: DataFrame, cond: Optional[RowFilter]) -> DataFrame:
    """Apply a SQL string, a Column, or a callable(df) -> Column."""
    if cond is None:
        return df
    if isinstance(cond, Column):
        return df.filter(cond)
    if isinstance(cond, str):
        return df.filter(F.expr(cond))
    if callable(cond):
        result = cond(df)
        if not isinstance(result, Column):
            raise TypeError("A callable row_filter must return a pyspark.sql.Column")
        return df.filter(result)
    raise TypeError("row_filter must be a SQL string, a Column or a callable(df) -> Column")


def align_to_target(src: DataFrame, tgt: DataFrame) -> DataFrame:
    """Select the target's columns that the source has, cast to the target's types, in target order."""
    src_cols = {c.lower(): c for c in src.columns}
    cols = [F.col(src_cols[f.name.lower()]).cast(f.dataType).alias(f.name)
            for f in tgt.schema.fields if f.name.lower() in src_cols]
    return src.select(*cols)


def add_missing_columns(spark: SparkSession, target_table: str, src: DataFrame) -> List[str]:
    """Explicit schema evolution: add source columns the target does not have (nullable)."""
    existing = {c.lower() for c in spark.table(target_table).columns}
    new = [f for f in src.schema.fields if f.name.lower() not in existing]
    if new:
        ddl = ", ".join(f"`{f.name}` {f.dataType.simpleString()}" for f in new)
        spark.sql(f"ALTER TABLE {target_table} ADD COLUMNS ({ddl})")
    return [f.name for f in new]


def commit_metrics(spark: SparkSession, table: str) -> Dict[str, int]:
    """operationMetrics of the latest commit in the table history, as integers."""
    row = DeltaTable.forName(spark, table).history(1).select("operationMetrics").first()
    raw = row[0] or {}
    return {k: int(v) for k, v in raw.items() if str(v).lstrip("-").isdigit()}


def build_slice(spark: SparkSession, source_table: str, key_candidates: Sequence[Sequence[str]],
                watermark_cols: Sequence[str], row_filter: Optional[RowFilter] = None,
                normalize_keys: bool = False, since: Optional[datetime] = None) -> Tuple[DataFrame, List[str]]:
    """Filtered source plus a _wm column, optionally limited to rows newer than `since`."""
    df = apply_row_filter(spark.table(source_table), row_filter)
    key_cols = choose_key(df, key_candidates)
    if normalize_keys:
        for k in key_cols:
            if isinstance(df.schema[k].dataType, StringType):
                df = df.withColumn(k, F.lower(F.trim(F.col(k))))
    df = df.withColumn("_wm", watermark_column(df, watermark_cols))
    if since is not None:
        df = df.filter(F.col("_wm") > F.lit(since))
    return df, key_cols

The function

def incremental_merge_scd1(
    spark: SparkSession,
    source_table: str,
    target_table: str,
    key_candidates: Sequence[Sequence[str]],
    watermark_cols: Sequence[str],
    *,
    row_filter: Optional[RowFilter] = None,
    transform_fn: Optional[Callable[[DataFrame], DataFrame]] = None,
    delete_condition: Optional[str] = None,   # SQL over source columns, e.g. "is_deleted = true"
    normalize_keys: bool = False,             # lower(trim()) string keys before dedup and merge
    create_if_missing: bool = True,           # bootstrap the target on the first run
    evolve_schema: bool = False,              # ALTER TABLE ADD COLUMNS for new source columns
    lookback_minutes: int = 0,                # re-read this much history to tolerate late arrivals
    watermark_value: Union[None, str, datetime] = None,  # control-table value; overrides the derived one
    tiebreak_cols: Sequence[str] = (),        # deterministic order when two rows share a watermark
    on_null_key: str = "fail",                # "fail" or "drop" rows whose key is null
) -> Dict[str, Any]:
    """Incremental SCD type 1 upsert from source_table into target_table (Spark, Delta)."""
    metrics: Dict[str, Any] = {"source": source_table, "target": target_table}

    exists = table_exists(spark, target_table)
    if not exists and not create_if_missing:
        raise ValueError(f"{target_table} does not exist and create_if_missing is False")

    # 1. High watermark: explicit value (control table) or derived from the target.
    last_wm = watermark_value
    if last_wm is None and exists:
        last_wm = last_watermark(spark, target_table, watermark_cols)
    if isinstance(last_wm, str):
        last_wm = datetime.fromisoformat(last_wm)
    since = last_wm - timedelta(minutes=lookback_minutes) if last_wm is not None else None
    metrics["last_watermark"] = str(last_wm) if last_wm is not None else None

    # 2. Filtered, watermark-sliced source. Filters run first so they can be pushed down.
    inc, key_cols = build_slice(spark, source_table, key_candidates, watermark_cols,
                                row_filter, normalize_keys, since)
    null_key = reduce(lambda a, b: a | b, [F.col(k).isNull() for k in key_cols])
    stats = inc.agg(
        F.count(F.lit(1)).alias("n"),
        F.max("_wm").alias("max_wm"),
        F.sum(F.when(null_key, 1).otherwise(0)).alias("null_keys"),
    ).first()
    nulls = int(stats["null_keys"] or 0)
    metrics.update(rows_in_slice=stats["n"], null_key_rows=nulls,
                   new_watermark=str(stats["max_wm"]) if stats["max_wm"] is not None else None)
    if stats["n"] == 0:
        metrics["mode"] = "noop"
        return metrics
    if nulls:
        if on_null_key == "fail":
            raise ValueError(f"{nulls} rows in {source_table} have a null key {key_cols}")
        inc = inc.filter(~null_key)

    # 3. Latest version per key, then split deletes from upserts and transform the upserts.
    latest = latest_per_key(inc, key_cols, "_wm", tiebreak_cols).drop("_wm")
    persisted = False
    try:
        deletes = None
        if delete_condition:
            is_deleted = F.coalesce(F.expr(delete_condition), F.lit(False))
            latest = latest.persist()
            persisted = True
            deletes = latest.filter(is_deleted).select(*key_cols)
            upserts = latest.filter(~is_deleted)
        else:
            upserts = latest
        if transform_fn is not None:
            upserts = transform_fn(upserts)   # must keep the key columns under the same names

        if not exists:
            upserts.write.format("delta").mode("errorifexists").saveAsTable(target_table)
            metrics["mode"] = "bootstrap"
            metrics["rows_inserted"] = commit_metrics(spark, target_table).get("numOutputRows")
            return metrics

        # 4. Optional explicit schema evolution, then align the source to the target.
        if evolve_schema:
            metrics["columns_added"] = add_missing_columns(spark, target_table, upserts)
        tgt = spark.table(target_table)
        src_df = align_to_target(upserts, tgt).withColumn("_op", F.lit("U"))
        if deletes is not None:
            src_df = src_df.unionByName(align_to_target(deletes, tgt).withColumn("_op", F.lit("D")),
                                        allowMissingColumns=True)
        keys_lower = {k.lower() for k in key_cols}
        cols = [c for c in src_df.columns if c != "_op"]
        set_map = {c: F.col(f"s.`{c}`") for c in cols if c.lower() not in keys_lower}
        insert_map = {c: F.col(f"s.`{c}`") for c in cols}
        cond = " AND ".join(f"t.`{k}` = s.`{k}`" for k in key_cols)

        # 5. One atomic MERGE. Clause order matters: the conditional delete comes first,
        #    the unconditional update last, and deleted keys are never inserted.
        builder = DeltaTable.forName(spark, target_table).alias("t").merge(src_df.alias("s"), cond)
        if deletes is not None:
            builder = builder.whenMatchedDelete(condition="s._op = 'D'")
        builder = builder.whenMatchedUpdate(set=set_map)
        builder = builder.whenNotMatchedInsert(
            condition="s._op = 'U'" if deletes is not None else None, values=insert_map)
        builder.execute()

        m = commit_metrics(spark, target_table)
        metrics.update(mode="merge", rows_inserted=m.get("numTargetRowsInserted"),
                       rows_updated=m.get("numTargetRowsUpdated"), rows_deleted=m.get("numTargetRowsDeleted"))
        return metrics
    finally:
        if persisted:
            latest.unpersist()

Using it for several tables

The per-table settings live in one dictionary, so adding a table is a configuration change, not new code. The examples show the three accepted filter shapes.

from pyspark.sql import functions as F

WATERMARK_COLS = ["last_modified_utc", "ingested_at_utc"]   # first non-null wins

# One entry per Silver table. The engine is the same for every table; only this dictionary changes.
SILVER_TABLES = {
    "customers": {
        "key_candidates": [["customer_id"], ["email"]],
        "row_filter": "customer_id > 0",                       # SQL string
        "delete_condition": "is_deleted = true",               # propagate source soft deletes
    },
    "departments": {
        "key_candidates": [["department_code"]],
        "normalize_keys": True,                                # codes arrive as 'HR', 'hr ', 'Hr'
    },
    "orders": {
        "key_candidates": [["order_id"]],
        "row_filter": F.col("status").isNotNull(),             # Column expression
        "delete_condition": "is_deleted = true",
        "lookback_minutes": 30,                                # tolerate late-arriving rows
    },
    "order_lines": {
        "key_candidates": [["order_line_id"], ["order_id", "line_number"]],
        "row_filter": lambda df: df["quantity"] >= 0,          # callable returning a Column
        "delete_condition": "is_deleted = true",
        "lookback_minutes": 30,
        "tiebreak_cols": ["order_line_id"],
    },
}

run_log = []
for table, cfg in SILVER_TABLES.items():
    metrics = incremental_merge_scd1(
        spark,
        source_table=f"brz.{table}",       # shortcut schema in the Silver lakehouse
        target_table=f"dbo.{table}",
        watermark_cols=WATERMARK_COLS,
        **cfg,
    )
    print(table, metrics)
    run_log.append(metrics)

The returned dictionary has mode (bootstrap, merge or noop), rows_in_slice, null_key_rows, last_watermark, new_watermark and, for a merge, the inserted, updated and deleted counts read from the Delta commit history. Write it to a run log table (see monitoring hooks).

What changed from the original utility

The original version had an update clause before its delete clause, so the delete could never fire; it compared keys null-safely, so null keys matched each other; it set schema auto-merge for the whole session; it added typed NULL columns for target columns missing from the source and then wrote those NULLs over existing values; it broke ties with a non-deterministic row id; and it estimated merged rows with an extra count. The appendix walks through each change line by line.

Handling deletes

A watermark filter only returns rows that still exist. A row deleted in the source simply stops appearing, and Silver keeps it forever unless something tells Silver it is gone. Decide per table which signal you have.

Soft-delete flags and change feeds

If the source marks deletions (is_deleted = true) or Bronze lands CDC records with an operation column, pass that as delete_condition. The flagged row carries a new watermark, so it arrives in the slice like any change; the MERGE deletes the matching Silver row and never inserts a flagged key. Do not filter flagged rows out with row_filter, or the delete never reaches the MERGE.

If downstream layers need to see deletions (Gold facts that must drop or reverse rows), keep the flag in Silver instead of deleting physically: leave delete_condition empty, keep is_deleted as a column and let Gold apply it. The Gold engine on the next page uses exactly that.

Key snapshot reconciliation

When the source deletes physically and there is no CDC, compare the full set of current source keys with Silver on a schedule, for example nightly, and flag or delete the Silver rows whose key has disappeared. Delta's WHEN NOT MATCHED BY SOURCE clause does this in one MERGE.

from delta.tables import DeltaTable
from pyspark.sql import functions as F

SOURCE, TARGET, KEY = "brz.orders", "dbo.orders", "order_id"
MIN_RATIO = 0.95   # refuse to run if the source key list looks truncated

source_keys = spark.table(SOURCE).select(KEY).distinct()
src_n, tgt_n = source_keys.count(), spark.table(TARGET).count()
if tgt_n and src_n < MIN_RATIO * tgt_n:
    raise RuntimeError(f"Source has {src_n} keys, target {tgt_n} rows: extract looks incomplete")

# Rows in the target whose key no longer exists in the source: flag them (or delete them).
(DeltaTable.forName(spark, TARGET).alias("t")
    .merge(source_keys.alias("s"), f"t.`{KEY}` = s.`{KEY}`")
    .whenNotMatchedBySourceUpdate(
        condition="t.is_deleted = false",
        set={"is_deleted": F.lit(True), "last_modified_utc": F.current_timestamp()})
    # .whenNotMatchedBySourceDelete()      # physical delete instead of a soft-delete flag
    .execute())

Guard against a truncated key list

If the Bronze extract failed halfway, the key list is short and the reconciliation flags or deletes rows that still exist. The ratio guard refuses to run when the source has noticeably fewer keys than the target. Tune the ratio to how many rows the source can legitimately delete between runs, and prefer a soft-delete flag so a mistake can be reversed.

Keeping merged tables healthy

  • Compaction. Frequent small MERGEs create small files. Run OPTIMIZE on a schedule, or rely on the table maintenance features of your runtime; see Delta Partitioning for layout.
  • Retention. VACUUM removes files older than the retention period. Keep enough history for time travel during incident analysis and for change data feed readers.
  • Low shuffle merge. Fabric's low shuffle merge setting reduces the rewrite cost of MERGE when a small share of rows change. Microsoft Learn documents it as enabled by default in Fabric Spark runtimes, at the cost of up to twice as many output files, which is one more reason to compact. Confirm the value in your runtime as described on the Environment page rather than setting it in every notebook.
  • Idempotency. A rerun of the same slice produces the same target: updates overwrite with the same values and inserts become updates. That is what makes a lookback and an automatic retry safe.

Key takeaways

  • A watermark finds inserts and updates; an increasing key finds inserts only; neither finds physical deletes.
  • Advance the mark only after the MERGE commits, and re-read a short lookback window to catch late commits.
  • Deduplicate to one row per key before MERGE and fail on null keys; a wrong key is the most expensive bug in this pattern.
  • Pick a delete signal per table: soft-delete flag, change feed, or a guarded key snapshot.
  • Keep the utility table-agnostic and the table differences in configuration.
